# 单词随机选择题 · 听读音版

> 一个**单文件、零依赖、离线可用**的背单词选择题工具。把整份词表丢进去，按页码范围随机出题，点一下喇叭就能听单词发音。

纯前端 HTML，不用 Node、不用构建、不用起服务器，双击就能用。词表、设置、答题进度全部存在本机浏览器里。

## 功能

| 能力 | 说明 |
| --- | --- |
| 随机出题 | 从词表随机抽词生成选择题，一次可出 **1–3000 题**，每题 2–6 个选项 |
| 三种方向 | 看英文选中文、看中文选英文、混合（每题随机） |
| 词典格式 | 支持 `单词 [音标] 词性 释义`，能正确拆音标、连续词性、多个义项 |
| 按页范围 | `1-20`、`前20页`、`21-40`、`20+`、`1-550词` 等，只测刚背过的那几页 |
| 听读音 | 题干/选项旁的 🔊 可点读，支持在线美音、英音和系统离线语音 |
| 干扰项 | 只从**当前范围**的词里取，不会掺进没背过的词；自动排除重复选项 |
| 即时判分 | 答完立刻显示对错、正确释义、音标与词性 |
| 错题本 | 交卷后可「只练错题」，也可导出错题词表 |
| 断点续答 | 中途关掉页面，下次打开可接着做；支持跳题号 |

## 快速开始

1. 下载本仓库，或直接取 `单词随机选择题_带读音.html` 这一个文件。
2. 用 **Chrome / Edge** 双击打开它（推荐 Edge）。
3. 在左侧粘贴词表，或点「导入文件」选择 `.txt` / `.docx` / `.csv`。
4. 设置出题范围、题目数量、方向，点「开始测验」。

> **Windows 提示**：请直接双击 `.html` 文件。系统里 `.url` 类型的「Internet 快捷方式」由旧 IE 组件处理，在 Win11 上打开本地 `file:///` 地址经常没反应。

## 词表格式

最常见的是带音标、词性的词典排版，一行一个词：

```text
fan [fæn] n.(运动等)狂热爱好者 风扇
abandon [əˈbændən] vt. 放弃 抛弃
look forward to 期待 盼望
be good at 擅长
```

解析规则：

- 音标只认第一个中文字符之前的 `[...]` 或 `/.../`，里面的逗号、句点不会干扰。
- 词性支持 `n. / v. / vt. / vi. / adj. / adv. / prep. / conj. / pron.` 等，也处理 `vt. & vi.` 这类连续写法。
- 也接受用 `Tab`、逗号、`=` 分隔的简易词表（如 `apple,苹果`）。
- 英文短语（含空格）不会在首个空格处被截断。
- 导入时自动识别 UTF-8 / GBK 编码；`.docx` 可直接读取，无需先另存为 txt。

**按页出题**依赖词表里的页码标记。本项目用的示例词表是从 PDF 转成 txt 时保留了页眉行，例如：

```text
考学位英语，用钉题库 APP 12
```

程序据此给每个词条打上页码，也兼容「第 N 天」这类分组标记。没有页码时会退化成按**词条序号**解释范围，并在界面上给出提示。

> 浏览器里的单文件页面无法直接解析 PDF。若你的词表是 PDF，请先用任意 PDF 转 txt 工具导出，保留页眉行，再导入本工具。

## 按页出题

在「出题范围」里填：

| 写法 | 含义 |
| --- | --- |
| `全部` / 留空 | 整个词表 |
| `1-20`、`前20页` | 第 1 到第 20 页 |
| `21-40`、`20+` | 第 21 到 40 页 / 第 20 页之后 |
| `1-550词`、`1-500词` | 按词条序号取前 550 / 500 个词 |

界面上有「前 20 页」「21-40 页」等快捷按钮，设置会自动保存到本机。

## 单词读音

发音入口按出题方向区分，避免「听一下就等于报答案」：

| 场景 | 怎么听 |
| --- | --- |
| 看英文 · 选中文 | 题干单词右侧的 🔊，或按 `P` 键 |
| 看中文 · 选英文 | 题干是中文，因此**每个英文选项**右侧各有小喇叭，点它只发音、不算作答 |
| 答完题后 | 反馈区的小喇叭可再听一次正确单词 |

「测验设置 → 单词读音」里可选：

- **在线发音 · 美音**（默认）/ **英音**：走词典发音接口，真人/标准发音，效果最好，需要联网。
- **系统语音 · 离线**：调用浏览器内置 `speechSynthesis`，自动优先挑英文语音。
- **出题自动读**：勾选后出题时自动朗读，仅在「看英文选中文」时生效（中→英时自动读会泄露答案）。

在线请求失败、断网或明确离线时，会自动回退到系统语音，不会卡住。切题、交卷、返回设置页时正在播放的音频会自动停止。

> 发音是唯一会产生网络请求的功能：点击喇叭时会把**该单词**作为 URL 参数请求 `dict.youdao.com`。除此之外，词表和答题数据不会离开本机。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `1`–`9` / `A`–`F` | 选择对应选项 |
| `Enter` / `空格` | 已作答时进入下一题 |
| `P` | 朗读当前题干单词（仅英→中） |

## 数据与隐私

- 全部逻辑在浏览器本地运行，没有后端、没有账号、没有埋点。
- 词表与设置：`localStorage` 键 `wordQuiz_v1`。
- 答题进度（题目、已答记录、错题）：`wordQuiz_progress_v2`。
- 清除浏览器站点数据会一并清掉这些内容；重要词表建议自己留一份 txt。
- 如上所述，仅「点喇叭听发音」会向第三方发音接口发送单个单词。

## 技术实现

单个 `.html` 文件内含 HTML / CSS / 原生 JS，没有任何外部库、CDN 或构建步骤。

- **词表解析**：正则拆分单词、音标、词性、中文释义；义项拆分时清理 `&`、`/` 等排版碎片。
- **出题**：预建候选池 + O(k) 抽样，取代逐题全表洗牌，几千题也能瞬间生成；干扰项去重并排除与答案文字相同的项。
- **docx 导入**：`FileReader` 读入后自写最小 ZIP 目录解析，用 `DecompressionStream('deflate-raw')` 解压 `word/document.xml` 再提取文本。
- **编码**：`TextDecoder` 自动尝试 UTF-8 / GBK。
- **发音**：`Audio` + 缓存（在线），`speechSynthesis`（离线兜底）。
- **持久化**：`localStorage`，断点恢复时重放已答题的标色，不重复计分。
- 纯逻辑函数与 DOM 层分离，可在 Node 里直接加载做单元测试。

## 已知限制

- PDF 不能直接导入，需先转成 txt（或 docx）。
- 在线发音需要联网；离线时改用系统语音，音色取决于系统安装的语音包（Windows 中文版常只有中文语音，英文发音效果会差一些）。
- 建议 Chrome / Edge；`file://` 下的 `localStorage` 与浏览器配置有关，换浏览器不会同步进度。
- 题目数量上限 3000；词数少于选项数时会自动降级选项数量。

## 常见问题

**双击没反应？** 直接双击 `.html` 文件，不要用 `.url` 快捷方式；也可右键选择「打开方式 → Microsoft Edge」。

**范围填了但没生效？** 检查导入的 txt 里是否还保留着页码页眉行；没有页码时会按词条序号解释，界面会有提示。

**换了带读音版，原来的词表和进度还在吗？** 在，同一个浏览器下 `file://` 页面共用本地存储，直接打开新版即可接着用。
